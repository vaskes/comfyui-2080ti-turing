## Goal

Confirm that the patched flash-attention works in current ComfyUI
with `--use-flash-attention`. This is **expected to be trivial**:
the official flash-attention Python interface
(`from flash_attn import flash_attn_func`) is what ComfyUI's
existing flash attention code path uses, so as long as the patched
package is installed in the comfyui container's venv,
`--use-flash-attention` should work without any ComfyUI code
change.

## Steps

1. **Confirm `flash_attn` is importable** in the comfyui container:
   `docker exec comfyui /opt/venv/bin/python3 -c "from flash_attn import flash_attn_func; print('OK')"`
2. **Start ComfyUI** with `--use-flash-attention` flag (in
   `compose.yaml` `COMFYUI_ARGS`). The current `COMFYUI_ARGS` is
   `"--listen 0.0.0.0 --port 8188 --disable-auto-launch --use-ck-attention"`.
   Change to add `--use-flash-attention`. Check the ComfyUI startup
   log for any "flash_attn not found" warnings.
3. **Check the ComfyUI log** for "Using flash attention" or
   similar — ComfyUI's
   `comfy/ldm/modules/attention.py:attention_flash` should be
   invoked when `--use-flash-attention` is set.

**Qwen code review:** review ComfyUI startup log, confirm
attention dispatch path is using flash-attn, approve.
