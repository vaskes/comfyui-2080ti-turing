## Goal

Build the patch + installer + test infrastructure. This is the
**first deliverable** in the Mavis coder's hands.

## Steps

1. **Clone `Dao-AILab/flash-attention`** at commit `965c921` to a
   local directory (`/opt/research/flash-attention` already exists
   on the workstation host from M0; reuse it).
2. **Apply the patch** from `patches/0001-add-sm75-arch.patch` to
   the cloned `setup.py`. Verify the patched file still has valid
   Python syntax (`python3 -c "import ast; ast.parse(open('setup.py').read())"`).
3. **Run `pip install --no-build-isolation --no-deps -e .`** inside
   the comfyui container with the env vars
   `FLASH_ATTN_CUDA_ARCHS=75;80;90;100;120` and
   `FLASH_ATTENTION_FORCE_BUILD=TRUE`.
4. **Resolve any build issues.** Likely: cuSparse/cuBlas headers
   (workaround: add
   `/opt/venv/lib/python3.12/site-packages/nvidia/cu13/{include,lib}`
   to include/library paths). C++20 (commit edb5c76; should be
   default for torch 2.13+). CUTLASS (bundled with
   cuda-toolkit-13-0 at `/usr/local/cuda/include/cutlass/`).
5. **Write `scripts/apply-patch-and-install.sh`** that automates
   the above.
6. **Write `tests/test_sm75_correctness.py`** with 5 unit tests:
   B=1,H=4,L=128,D=64; B=1,H=4,L=128,D=128; B=2,H=8,L=256,D=128;
   causal mask D=128; causal mask D=64. Compare `flash_attn_func`
   vs `F.scaled_dot_product_attention`. Pass: `max_abs_diff < 0.05`.
7. **Commit and push** to `vaskes/comfyui-2080ti-turing` main.

**Qwen code review:** review build log, patched setup.py diff,
test script, install script. Approve before M2.
