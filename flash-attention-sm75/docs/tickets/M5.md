## Goal

Validate the speed of the patched flash-attention on sm_75. This
is the **aspirational** milestone: we are not chasing a speed
record, we are documenting what we get for free.

The bar is `≤ 5% slower than the comfy_kitchen sol_attn baseline
(140 s for Qwen, 1:45 for H3)`. Speed beyond this is a bonus,
not a requirement.

## Steps

1. **Run the bench:** the existing `comfyui_run.py` helper already
   captures timing. Run Qwen and H3 workflows 3 times each with
   warm cache, report median time.
2. **Compare with baselines:** the existing test runs in
   `docs/tasks/01-flash-sm75-native.md` Context section give us
   the baselines (140 s Qwen, 1:45 H3).
3. **Document the result** in
   `flash-attention-sm75/tests/SPEED.md`:
   - Qwen: `<our_time> s` vs `<baseline> s` = `<ratio>`
   - H3: `<our_time>` vs `<baseline>` = `<ratio>`
   - Verdict: faster / same / slower

**Qwen code review:** review the bench methodology, the comparison
with baselines, the verdict. Note: per the task document, even
a "slower" verdict is a successful resolution of this task
(correctness bar is met; speed is bonus).

## Pass criteria

- [ ] Bench completed, medians reported
- [ ] Qwen ≤ 147 s OR document why slower (memory traffic?
      unoptimized kernel path? — these become follow-up tasks)
- [ ] H3 ≤ 1:45 × 1.05 OR document why slower
- [ ] `flash-attention-sm75/tests/SPEED.md` committed
- [ ] M5 commit pushed
